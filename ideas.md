# Kavay Khurana Portfolio — Design Direction

## Three visual approaches considered

| Theme Name | Very Brief Intro | Probability |
|---|---|---:|
| Terminal Garden | A quiet, editorial developer portfolio where structured backend systems meet the warmth of a personal learning journey. It feels rigorous without looking sterile. | 0.07 |
| Clay & Copper | A tactile, analog-inspired résumé experience using paper, ink, and copper accents to present an early-career technologist with confidence. | 0.04 |
| Night Transit | A dark, energetic interface inspired by city infrastructure and data routes, with light trails that represent application flow. | 0.09 |

## Chosen approach — Terminal Garden

### Design Movement
**Editorial software craftsmanship** with subtle references to developer tooling and technical field notes. The site should feel like a well-maintained engineering notebook rather than a generic recruiting landing page.

### Core Principles
1. Use **clear information hierarchy**: a visitor can understand Kavay's role, readiness, and strongest signals in one glance.
2. Balance **systems precision and human warmth** through monospaced metadata, expressive display typography, and imperfect organic accents.
3. Make the student-to-engineer trajectory visible with honest language, concrete indicators, and project-led storytelling.
4. Favor **asymmetry and sequential reading** over stacked, centered marketing blocks.

### Color Philosophy
The foundation is warm parchment rather than white, representing working notes and learning in public. A deep ink-green signals backend reliability and the signature lime-green offers a distinct, optimistic “build in progress” highlight. Copper-brown is reserved for secondary emphasis and timeline details.

### Layout Paradigm
The page is designed as a flowing **engineering field notebook**: a slim, persistent rail contains navigation and status; the main canvas has staggered “entries” that alternate between large editorial blocks and compact technical cards. Responsive layouts turn the rail into a compact header while retaining the sequential narrative.

### Signature Elements
1. A **route diagram** in the hero: connected nodes show a request moving through a Java service, database, and response.
2. **Notebook tabs and file labels** as section markers, such as `01 / profile` and `03 / projects`.
3. A small **availability signal** reading “Open to internship opportunities” that recurs as a quiet status motif.

### Interaction Philosophy
Interaction is informative, not ornamental. Project cards lift slightly to reveal tools and destination links. Navigation scrolls with intention. The route diagram responds subtly to pointer movement and works without interaction. Every external link is clearly marked.

### Animation
Entrance motion is gentle and ordered: the hero text appears first, followed by the route nodes, then supporting metadata in 50–80ms steps. Hover motion is capped at 180ms with a crisp ease-out. Route pulses are extremely restrained and disabled for reduced-motion preferences. Buttons compress slightly when pressed.

### Typography System
**DM Serif Display** provides a distinctive, thoughtful voice for major headlines; **Manrope** supports compact, highly legible body copy; **IBM Plex Mono** is used for labels, stats, repositories, and system-inspired details. Headlines use high contrast scale rather than all-caps decoration.

### Brand Essence
**Kavay Khurana is an aspiring Java backend engineer building dependable systems through deliberate practice, projects, and problem solving.**

Personality: **methodical, curious, grounded**.

### Brand Voice
The voice is candid, concise, and engineering-led. It avoids inflated claims and treats learning as evidence of momentum.

Example lines:

> “From problem sets to service layers—building the habits behind reliable software.”

> “538 solved. Still tracing the next edge case.”

### Wordmark & Logo
The mark is a **two-node request/response loop**: two offset circles joined by a squared route, visually forming an abstract `K` while implying a backend data flow. The wordmark uses restrained serif italics beside monospaced role metadata.

### Signature Brand Color
**Service Lime — `#B9F25C`**. This precise yellow-green is used sparingly for route activity, key metrics, focus rings, and the availability signal.

## Style Decisions

- Keep the visual language light, tactile, and code-adjacent; never use generic card grids or neon cyberpunk treatments.
- Preserve honest positioning: Kavay is a TIET CSE student seeking Java backend internship opportunities, not an experienced engineer claiming prior employment.
- LeetCode and GitHub activity are presented as evidence of practice and momentum, with direct links to their source profiles.
- The two-node request/response `K` mark and Kavay Khurana wordmark are visible in the opening viewport, paired with concise monospaced role metadata.
- The field-notebook rail is reinforced through linked navigation nodes and a recurring vertical route spine that guides the visitor from profile through contact.
- Service Lime remains reserved for live-system activity, primary action, availability, and key metrics; copper carries secondary editorial emphasis.
